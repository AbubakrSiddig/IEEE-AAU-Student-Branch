# IEEE AAU Student Branch Platform 🚀
### المنصة الرسمية لفرع IEEE بجامعة الزعيم الأزهري

تم بناء المنصة بالكامل استناداً إلى **وثيقة المتطلبات v0.3** ومطابقة لجميع شاشات التصميم الـ 19 المرفقة، مع دمج الشعارات الرسمية (النسخة البيضاء والنسخة الزرقاء) ودعم كامل للغتين **العربية (RTL)** و**الإنجليزية (LTR)**.

### ب) مسار التسجيل متعدد الخطوات (Registration Wizard)
- **الخطوة 1: الشروط والأحكام (Screen 10):**
  - شريط خطوات تفاعلي (Terms → Personal → Academic → Review & Submit).

  - زر تنزيل الشروط PDF مع حفظ رقم الإصدار وتاريخ الموافقة.
- **الخطوة 2: البيانات الشخصية (Screen 11):**
  - الاسم الكامل، البريد، الهاتف، تاريخ الميلاد، الجنس، الجامعة.

### ج) لوحة التحكم الإدارية (Admin Dashboard)
1. **لوحة المؤشرات (Dashboard - Screen 14):**
   - الشريط الجانبي الداكن (`#0B192C`) بشعار IEEE الأبيض وروابط الأقسام.
   - بطاقات إحصائيات: إجمالي الطلبات (+12%)، إجمالي الأعضاء (+6%)، المتطوعون النشطون (+15%)، الفعاليات القادمة (+20%).
   - رسم بياني خطي تفاعلي: **Membership Growth** (نمو العضوية خلال العام).
   - رسم بياني دائري تفاعلي: **Applications by Status** (Pending / Accepted / Rejected).
   - جدول أحدث الأنشطة والعمليات (Recent Activities).

2. **إدارة الطلبات (Applications - Screen 15):**
   - جدول كامل مع الفرز والبحث وفلاتر الحالة والتخصص.
   - شارات الحالة الملونة (Pending باللون الأصفر، Accepted بالأخضر، Rejected بالأحمر).
   - **تصدير إلى Excel (.xlsx):** توليد ملف إكسل حقيقي للبيانات المفلترة الحالية عبر SheetJS.
   - نافذة فحص تفاصيل الطلب وتغيير حالته فورياً مع حفظ السجل.

3. **إدارة الأعضاء (Members - Screen 16):**
   - جدول الأعضاء، فلاتر الفرق والسنوات الدراسية، إضافة عضو جديد، تعديل، وأرشفة.
   - تصدير ملفات Excel للأعضاء.

4. **إدارة الفعاليات (Events - Screen 17):**
   - جدول الفعاليات وحالاتها، إضافة وتعديل الفعاليات وتحديد المتحدثين والمقاعد.

5. **التقارير وتصدير Excel و ZIP (Screen 18):**
   - تحديد نوع التقرير (Members / Applications / Events / Volunteers) والفترة الزمنية.
   - زر **Generate** لتحديث وتوليد التقرير بصيغة Excel.
   - زر **Download All (ZIP):** يجمع كل تقارير النظام في ملف مضغوط واحد `.zip` بضغطة زر.

6. **إدارة الشروط والأحكام (Terms Management - Screen 19):**
   - جدول إصدارات الشروط (v2.0 النشط، v1.0).
   - زر **Create New Version** لإصدار لوائح جديدة.
   - محرر نصوص لتعديل وحفظ نصوص الشروط.
   - زر تنزيل وثيقة الشروط بصيغة PDF.

7. **إدارة المتطوعين والإعدادات:**
   - فرز وتصنيف متطوعي الفرق وتغيير حالاتهم.
   - زر استعادة بيانات العرض التوضيحية الأصلية في أي وقت.

## 🛠️ التقنيات والمكتبات المستخدمة

- **Front-end:** Vue 3 (Composition API) + Tailwind CSS + Lucide Icons.
- **التفاعل والرسوم:** Chart.js للرسوم البيانية، Canvas-Confetti، عدّادات تفاعلية، عدّ تنازلي حي.
- **تصدير الملفات:** 
  - `xlsx` (SheetJS) لتوليد وتصدير ملفات Microsoft Excel الحقيقية.
  - `jspdf` لتوليد مستندات PDF للشروط والمجلة.
  - `jszip` و `file-saver` لضغط التقارير في حزمة ZIP.
- **دعم اللغات:** محول لغة فوري مع قلب الاتجاه التلقائي `dir="rtl"` و `dir="ltr"` والخطوط العربية اللاتينية المناسبة (Cairo + Inter).
- **Back-end & XAMPP:**
  - يعمل مباشرة على XAMPP Apache عبر الرابط المباشر.
  - ملف `api.php` خفيف ومتوافق مع PHP 7.1+ و PHP 8.x لتقديم البيانات بصيغة JSON.
  - حفظ وتزامن فوري في المتصفح `localStorage` بحيث تحفظ أي طلبات أو تعديلات وتنعكس فوراً في الواجهة ولوحة التحكم.

## 🚀 كيفية التشغيل

### الخيار 1: تشغيل فوري عبر XAMPP Apache
1. شغل برنامج **XAMPP Control Panel**.
2. اضغط **Start** بجانب **Apache**.
3. افتح المتصفح على الرابط:
   ```
   http://localhost/IEEE AAU SB PLATFORM/
   ```
   أو مباشرة:
   ```
   http://localhost/IEEE AAU SB PLATFORM/dist/
   ```

### الخيار 2: بيئة التطوير المباشرة (Hot-Reload Dev Server)
في مجلد المشروع شغّل:
```bash
npm run dev
```
افتح المتصفح على الرابط الموضح (عادة `http://localhost:3000`).

### الخيار 3: إعادة بناء الحزمة (Production Build)
عند تعديل أي ملف في `src`:
```bash
npm run build
```
تُبنى الحزمة المحسنة في مجلد `dist/` تلقائياً.
